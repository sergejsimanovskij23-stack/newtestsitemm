# 🛏️ МатрасОнлайн — Магазин матрасов

Современный интернет-магазин матрасов с админ-панелью, готовый к деплою на Vercel.

## 🚀 Быстрый старт

### 1. Клонируй репозиторий
```bash
git clone https://github.com/ТВОЙ_ЮЗЕРНАМЕ/mattress-store.git
cd mattress-store
```

### 2. Установи зависимости
```bash
npm install
```

### 3. Запусти локально
```bash
npm run dev
```
Открой `http://localhost:3000` в браузере.

### 4. Проверь сборку
```bash
npm run build
```

## 🌐 Деплой на Vercel (бесплатно)

### Шаг 1: Загрузи на GitHub
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/ТВОЙ_ЮЗЕРНАМЕ/mattress-store.git
git push -u origin main
```

### Шаг 2: Подключи к Vercel
1. Зайди на [vercel.com](https://vercel.com)
2. Нажми **"Add New Project"**
3. Выбери репозиторий `mattress-store`
4. Нажми **"Deploy"**

Vercel автоматически:
- Установит зависимости (`npm install`)
- Соберёт проект (`npm run build`)
- Развернёт сайт

### Шаг 3: Настрой переменные окружения (опционально)
В Vercel → Project Settings → Environment Variables:
```
ADMIN_PASSWORD=admin2024
```

## 🛒 Функционал

### Для покупателей:
- ✅ Главная с акциями
- ✅ Каталог с фильтрацией по категориям
- ✅ Детальная страница товара
- ✅ Оставить заявку (имя, телефон, email, сообщение)
- ✅ Адаптивный дизайн (телефоны, планшеты, десктоп)

### Для администратора:
- 🔒 Вход по паролю
- ✅ Добавление новых товаров (название, цена, категория, фото, описание, характеристики)
- ✅ Редактирование товаров
- ✅ Удаление товаров
- ✅ Просмотр и управление заявками (смена статуса)

### Безопасность:
- 🔒 Middleware защищает админ-панель
- Cookie-based аутентификация (httpOnly)
- Пароль хранится на сервере

## 🎨 Дизайн
- Цветовая схема: бирюзовый + фиолетовый акцент
- Tailwind CSS
- Glass-morphism эффекты

## 📦 Технологии
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Server Actions** для формы заказа
- **JSON-file storage** (для демо; для продакшена рекомендуется БД)

## ⚠️ Важно
- Данные хранятся в `data/store.json` (работает локально и на Vercel в пределах одного запуска)
- Для production рекомендуется подключить базу данных (Supabase, MongoDB, PostgreSQL)
- Пароль админа по умолчанию: `admin2024` — **обязательно смени!**
